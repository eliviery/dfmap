# dfmap

Este projeto contém arquivos HTML e JSON relacionados às regiões de Arapoanga e Planaltina.

## Estrutura
- `arapoanga.html`: Mapa ou informações sobre Arapoanga
- `planaltina.html`: Mapa ou informações sobre Planaltina
- `features-arapoanga.json`: Dados de recursos para Arapoanga
- `features-planaltina.json`: Dados de recursos para Planaltina

## Como usar
Abra os arquivos HTML em um navegador para visualizar os mapas. Os arquivos JSON fornecem dados de recursos que podem ser utilizados para visualização ou análise.

## Requisitos
Nenhum requisito específico. Basta um navegador para visualizar os arquivos HTML.
